# Своя гра

Локальний веб-застосунок для проведення гри «Своя гра» на одному екрані (ноутбук → проєктор/ТВ). Ведучий керує грою через інтерфейс, команди відповідають усно.

Повна специфікація проєкту — у файлі [`prompt-svoya-gra.md`](./prompt-svoya-gra.md).

## Стек

- **Frontend:** React 19 + Vite, TypeScript, CSS Modules + CSS custom properties (теми)
- **Backend:** Express 5 + TypeScript (Node.js)
- **Тести:** Vitest (бали, черга, перехоплення, валідатор паку — усе в `/shared`)
- **Зберігання:** JSON-файли та медіа на диску, без бази даних

Вимоги: Node.js **24+**.

## Встановлення і запуск

```bash
npm install        # один раз, встановлює всі три workspace
npm start           # зібрати все й піднести застосунок на http://127.0.0.1:3000
```

Для розробки (Vite dev-сервер з HMR + сервер у watch-режимі):

```bash
npm run dev          # клієнт на http://localhost:5173 (проксі на API), сервер на :3000
```

Тести:

```bash
npm test             # vitest run для /shared
```

Сервер слухає лише `127.0.0.1` і призначений для роботи офлайн — усі шрифти підключені локально, без зовнішніх CDN.

## Структура репозиторію

```
/client        React + Vite — головний екран, адмінка, режим гри
/server        Express 5 API + роздача статики й медіа (з HTTP Range)
/shared        TS-типи моделі даних + чиста логіка гри (бали, черга, перехоплення,
                рейтинг, валідатор паку) — усе покрите тестами Vitest
/data          створюється автоматично, у .gitignore
  /packs/<packId>/pack.json
  /packs/<packId>/media/<uuid>.<ext>
  /sessions/<sessionId>.json
```

## Демо-пак

При першому запуску (якщо `data/packs` порожній) сервер автоматично копіює готовий демо-пак із `server/assets/demo-pack`: 2 раунди, текстові питання, картинка, аудіо- та відео-заглушки, одне порожнє поле в сітці та питання з варіантами відповіді. Його можна одразу запустити з головного екрана («Гра» → обрати пак), не заходячи в адмінку.

## Головний екран

Дві кнопки — **«Гра»** і **«Адмін»**, перемикач теми (темна/світла, запам'ятовується) і кнопка повноекранного режиму.

## Адмін-режим

Нейтральний світлий інтерфейс для редагування паків:

- список паків зі статусами («Чернетка» / «Готовий»), дублювання, видалення, експорт/імпорт `.zip`;
- редактор паку: метадані, раунди (ціни з автопідстановкою), категорії, сітка-прев'ю;
- редактор питання: блоки контенту й відповіді (текст/картинка/аудіо/відео), варіанти A–D;
- «Позначити готовим» запускає валідацію й показує список помилок з переходом до проблемного місця;
- попередження, якщо по паку зараз іде незавершена гра.

## Режим гри

Вибір паку (лише зі статусом «Готовий») → стартовий екран з назвою по дузі → додавання команд (2–8) → рулетка вибору першої команди → ігрове поле → питання → (за потреби) перехоплення → відповідь → наступний раунд → фінал з рейтингом.

Стан сесії автоматично зберігається на сервері після кожної дії — `F5` або закриття вкладки посеред гри відновлює її з того самого місця (діалог «Продовжити гру / Нова гра» при вході).

### Гарячі клавіші (режим гри)

Не перехоплюються, коли фокус у полі вводу.

| Клавіша | Дія |
| --- | --- |
| `F` | Повноекранний режим |
| `H` | Приховати/показати рахунок |
| `T` | Перемкнути тему |
| `Space` | ▶/⏸ поточного аудіо/відео |
| `Esc` | Закрити відкритий діалог (не скасовує нарахувань) |
| `1`–`8` | Підказка-виділення команди на панелі перехоплення |
| `?` | Шпаргалка гарячих клавіш |

## Поза межами v1

Спецпитання («Кіт у мішку», «Аукціон»), таймер відповіді, звукові ефекти, мультимовність, логін, гра з кількох пристроїв, фінальний раунд зі ставками.
